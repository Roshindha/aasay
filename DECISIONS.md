## Additional decisions

- **F1 Forbidden name.** `PLAN.md` (the user-supplied spec) contains the former name and the plan's layout used a directory name derived from it. The detector modules live in `src/lanes/` instead of the directory name the plan's layout used. `PLAN.md` itself is the only file excluded from the forbidden-name check; it is left unedited because it is the user's spec.
- **F2 Versions.** Pinned `typescript@5` (not 7), `eslint@9`, `vitest@3` for compatibility with `eslint-config-next@16`; `@types/node@22`. `diff@8`.
- **F3 Registry 404 semantics.** A 404 for a scoped package, or any lookup when a custom registry is configured (`.npmrc` registry / `.npmrc` scope registry, `pip.conf`/`--index-url`/`[[tool.poetry.source]]`), is `likely`, not `confirmed`.
- **F4 Patch application.** Gate uses `git apply` in a temp dir (fallback `patch -p1`); diffs are generated with the `diff` package.
- **F5 Tests of MCP.** The stdio test spawns the server through `tsx` and talks to it with the SDK client.
- **F6 Local Python modules.** Any file stem or directory name inside the scanned repo counts as a local module (covers sibling and src-layout imports); this can mask a third-party import that shares a name with a repo directory.
- **F7 (superseded by F26) OpenAI host.** An opt-in OpenAI client pinned to `api.openai.com` was originally added as an exception to the host allowlist. It has been removed; see F26.
- **F8 Lane naming.** Detector lanes live in `src/lanes/`; the heuristic lanes are deterministic and the LLM adds only `speculative` findings.
- **F9 Seeded benchmark.** 11 planted bugs (3 hallucination, 3 spec-drift, 3 test-theater, 2 phantom-dependency) in `fixtures/seeded-demo`; the detectors were written alongside the fixture so the 100% score shows plumbing works, not real-world accuracy. Line tolerance 1. Gate: recall >= 0.8, precision >= 0.8, critical recall = 1.0.
- **F10 Non-planted deps behaviour.** Typosquat and transitive-only detection are implemented and unit-tested but intentionally not planted in the seeded demo (the plan specifies exactly two planted phantom bugs).
- **F11 Gate checks.** With no install step available in the temp dir, built-in checks are: `git apply --check` + apply, JSON validity for patched `.json`, and `ast.parse` for patched `.py` (skipped if `python3` is absent). Callers may add `checks` (used by the secrets test). A candidate is eligible only if it applies and every check passes. Check subprocesses get an allowlisted env (`PATH LANG LC_ALL TERM TZ SHELL` + `HOME`=temp dir, `CI=1`), and any name matching `KEY|TOKEN|SECRET|PASSWORD|PASSWD|CREDENTIAL|AUTH|COOKIE|SESSION` is dropped even if explicitly provided.
- **F12 Scoring.** Five axes in [0,1], weighted correctness .40, safety .20, minimality .15, maintainability .15, testability .10. Correctness is measured, not guessed: the full review is re-run on the patched tree (finding must disappear; −0.3 per new medium+ finding; −0.45 for dangling references to removed imports). Non-applying/failed-check candidates are ineligible and score 0.
- **F13 Patch coverage.** Generators exist for: phantom deps (remove / replace / replace+declare / declare / comment-out), missing exports (alias / rename), invented APIs (replace), constant drift (set to spec), tautological assertions (delete / failing TODO). Signature drift and no-assertion tests intentionally get no auto-patch (need human judgement). Replacement names for phantom packages come from a small hand-curated table (`src/patches/replacements.ts`) plus the typosquat target; the semantic fit of a replacement is not verified.
- **F14 UI.** One-page dashboard (`src/app/dashboard.tsx`) over route handlers `/api/seeded`, `/api/live`, `/api/tournament`. Recall/precision/gate are shown only for the seeded run; live scans show counts only (no answer key). A shared service layer (`src/core/service.ts`) keeps an in-memory store of recent scans, used by both the UI and MCP. `turbopack.root` set in `next.config.mjs` to silence the parent-lockfile warning. The build prints a benign "dynamic filesystem access" tracing warning for the fixtures reader; the app is local-only.
- **F15 GitHub fetch.** PR scans fetch changed reviewable files plus all manifests/specs from the PR head tree (for context); repo scans fetch manifests plus code up to 80 files / 150 KB each. Only `api.github.com` is contacted; `GITHUB_TOKEN` is sent only there.
- **F16 MCP.** `src/mcp/server.ts` (name `assay`, stdio). Tools: assay_review, assay_fix, assay_score_patch, assay_handoff, assay_eval, assay_check_deps. Resources: `assay://findings`, `assay://evidence-graph` (latest scan), `assay://answer-key`. Prompts: `review`, `fix_handoff`. Scans are kept in process memory and addressed by `scanId`. `source=path` reads a local directory the client names (local trust model, capped at 300 files / 200 KB each). The stdio test spawns the server via `tsx` with `ASSAY_OFFLINE=1`.
- **F17 refresh-popular.** npm refreshes via the registry search endpoint (popularity-ranked, allowed host). PyPI has no ranking endpoint on an allowed host, so `--pypi-file` takes a locally downloaded ranking; the script never invents names. Not run in this build (no refresh was needed; fixtures are the hand-curated snapshots).

## UI polish (separate pass; UI layer only)

- **F18 No new runtime dependencies.** Everything is Tailwind + inline SVG icons + system fonts; no icon/font/CDN assets. New *dev* dependencies only: `@playwright/test` (smoke + screenshots), `@axe-core/playwright` (WCAG 2.1 A/AA scans in both themes), `@testing-library/{react,jest-dom,user-event}`, `jsdom`, `@vitejs/plugin-react` (Vitest JSX). Pins: `jsdom@26` (jsdom 31 needs Node ≥ 24.15; this machine has 24.7) and `@testing-library/jest-dom@6` (v8 needs Vitest 5; we use 3).
- **F19 Config touched outside `src/app`.** `vitest.config.ts` (also include `*.tsx`, React plugin; UI tests opt into jsdom via a docblock so the logic tests still run in node), `tsconfig.json` (include `e2e/` and `.tsx` tests), `playwright.config.ts`, `package.json` scripts (`e2e`, `screenshots`). No logic module, fixture or MCP file changed.
- **F20 Visual direction.** Neutral dark theme by default with a light theme; first load follows `prefers-color-scheme`, a toggle persists the choice (inline pre-paint script, so no flash). Colour roles: *confirmed* = red accent, *likely* = amber accent, *speculative* = muted grey. Severity is never shown by hue (4-step meter + text), so labels own the accents. Label and severity always have an icon/shape plus text. Contrast is unit-tested from the CSS tokens (`tests/ui-contrast.test.ts`) and scanned with axe in the browser.
- **F21 Navigation.** Hash routes (`#/verdicts`, …) so views are deep-linkable. Nav has three groups (Run / Analyze / Fix). "Context budget" is both a compact panel (Seeded view) and its own nav entry. A top-bar Seeded/Live switch chooses which scan the Analyze/Fix views show; running a live scan switches to it. This replaces the old Seeded/Live toggle + tab strip; behaviour of the seeded run, live scan and tournament API calls is unchanged.
- **F22 Offline/online indicator is derived, not reported.** The UI shows "Offline · recorded fixtures" for the seeded source (always true), "Online · GitHub, npm, PyPI" once a live scan exists, and "Browser offline" from `navigator.onLine`. The server does not expose whether `ASSAY_OFFLINE=1` was applied to a live scan, so a live scan run with that variable would still be labelled online. Fixing this needs an API field (a logic change), so it was left alone.
- **F23 Error scrubbing.** `ErrorState` redacts token-like strings (`ghp_…`, `github_pat_…`, `sk-…`, `Bearer …`, `?access_token=…`) before display, in addition to the server never including tokens.
- **F24 Graph.** Nodes carry visible kind words and an accessible name equal to their visible text (axe `label-content-name-mismatch`); full labels are shown in the inspector rather than as SVG tooltips. Under 768px the graph is replaced by a grouped list; on desktop a Graph/List toggle is available.

## Finishing pass

- **F25 `offline` is reported by the API.** Every scan carries `offline: boolean` (seeded route, live route, MCP `assay_review`/`assay_check_deps`). It is `true` when `ASSAY_OFFLINE=1`, when the offline option was used, or when no registry lookup actually went to the network (all answers from recorded fixtures, the popular snapshot, or the disk cache). It is `false` only if at least one registry request left the machine (`RegistryClient.networkCalls > 0`). It describes *registry* lookups only: a GitHub scan still fetches from `api.github.com`, which is why the badge reads "Offline · registry from fixtures/cache" rather than "Offline" for live scans. The badge uses this field; the earlier inference (F22) is superseded.
- **F26 The allowlist is absolute; OpenAI removed.** `OpenAiLlmClient`, the `openai` dependency (package.json, lockfile, `next.config.mjs`), `ASSAY_LLM`, `OPENAI_API_KEY` and `ASSAY_MODEL` handling, and the related README/`.env.example` entries are gone. `HeuristicLlmClient` is the only `LlmClient`. The only outbound hosts are `api.github.com`, `registry.npmjs.org` and `pypi.org`. If a model-backed reviewer is added later it should be a separate module with its own explicit allowlist entry, its own tests, and a documented opt-in, rather than a carve-out in the data allowlist. Remaining textual matches for "openai" in the repo are: the package *name* in the popular-package snapshots, this file, one regression test (`tests/llm.test.ts`) that sets those variables to prove they are ignored, and the user-supplied `PLAN.md`.
- **F27 Dependencies on mobile.** Under 768px (`md`) the issues table is replaced by stacked cards (package, registry, status as icon + text, verdict, location); at ≥768px the table is shown and the cards are hidden. Both are in the DOM; CSS picks one.
- **F28 Graph node labels.** Nodes now show the full label wrapped to at most two lines (per-column widths: findings 300, files 190, dependencies 250, manifests 170); only text beyond two lines is truncated, with an ellipsis. The kind tag moved out of the node (column headers show it; the accessible name still starts with the kind). Full text is always in the inspector and in the node's accessible name. Hover tooltips stay removed. Supersedes the node-label part of F24.
